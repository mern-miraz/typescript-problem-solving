# TypeScript Problem Solving

This repository contains my TypeScript assignment solutions and blog posts.

I created this repository as part of my TypeScript learning journey. Here, I have practiced different TypeScript concepts by solving problems and writing about what I have learned.

## What I Learned

In this repository, I worked with the following topics:

- Basic types and functions
- Optional and default parameters
- Union types and type narrowing
- Readonly tuples
- Interfaces and type aliases
- Array methods
- Generics
- `keyof` and constraints
- Classes and inheritance
- Access modifiers
- Promises and async/await

## Repository Contents

### 1. `solutions.ts`

This file contains my solutions to different TypeScript problems. I tried to use the concepts I learned in the course to solve each problem.

### 2. `type-vs-interface.md`

In this blog, I explained the differences between `type` and `interface` in TypeScript, their features, and when to use them.

### 3. `access-modifiers-in-typescript-oop.md`

This blog is about access modifiers in OOP. It explains `public`, `private`, `protected`, and `readonly` with their uses.

## How to Run

First, clone this repository:

```bash
git clone https://github.com/mern-miraz/typescript-problem-solving.git
```

Go to the project folder:

```bash
cd typescript-problem-solving
```

Run the TypeScript file:

```bash
npx tsx solutions.ts
```
